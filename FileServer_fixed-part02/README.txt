# FileServerApp (Java, IntelliJ Ready)

## Structure
FileServerApp/
  src/
    FileServer.java
    FileClient.java
  server_files/
  client_files/

## Steps to Run (LAN)
1. Extract ZIP
2. Open in IntelliJ
3. First run FileServer.java on SERVER PC
4. Then run FileClient.java on CLIENT PC
5. Server IP is already fixed in FileClient.java (192.168.0.101) — change if needed
6. Use commands: list, upload, download, delete, exit
